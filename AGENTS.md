# Fluxo deste projeto

- Nunca iniciar servidor local, incluindo servidores estáticos e comandos dev.
- Validar com `npm run check`, `npm test` e `npm run build`.
- Revisão visual somente na versão publicada pela Vercel.
- Manter HTML, CSS e JavaScript nativos e evitar dependências desnecessárias.
- Dados compartilhados e imagens: `src/config.mjs`.
- Utilizar `.agents/skills/frontend-design/SKILL.md` como referência visual.
- Após implementar e validar alterações solicitadas, fazer commit e push na branch atual.
- Não gerar imagens; utilizar placeholders identificados até o usuário fornecer fotos.
